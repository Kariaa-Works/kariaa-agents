# Remotive

Remote jobs from [Remotive](https://remotive.com), through its public API (`/api/remote-jobs`). Find only.

- Search by words (`search=`); region filtering runs here on the "candidate required location".
- Jobs appear 24 hours after Remotive lists them.
- Remotive asks that results link back to its job page and credit it as the source: every job carries Remotive's `url` and the tag `source:remotive`.
- No key.
